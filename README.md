# TODO Service

Сервис предоставляет стандартные CRUD операции по работе с задачами. Сервис написан на Go и использует стандартный net/http.

## Возможности
- Создание задачи
- Получение задачи по ID
- Получение списка задач
- Фильтрация по статусу выполнения
- Пагинация (limit, offset)
- Обновление задачи
- Удаление задачи

## Детали реализации
- Используется только стандартная библиотека (за исключением генерации моков)
- Слоистая архитектура
- Сервис запускается в контейнере с помощью docker compose
- Graceful shutdown для корректного завершения приложения
- Swagger / OpenAPI документация
- API и service слои покрыты unit тестами с использованием моков (gomock)

## Быстрый старт
### Запустить приложение вместе с зависимостями
```bash
task up-service
```
Сервис будет доступен по адресу: `http://localhost:8080`
### API документация (Swagger)
Swagger UI доступен по адресу: `http://localhost:8080/swagger/index.html`
Документация генерируется с помощью swaggo/swag и описывает все доступные эндпоинты, параметры и ответы.

### Завершить работу сервиса
```bash
task down-service
```
